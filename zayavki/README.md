# Заявки CrazyDrift (zayavki.drozdgid.ru)

Панель для администраторов и банкетных менеджеров. Заменяет связку «написали заявку в чат Битрикс24 → вручную перенесли в Google-таблицу „Брони“». Администратор вписывает заявку один раз, и она сразу попадает в таблицу банкетного менеджера, который сейчас на смене.

Консоль маркетолога (pult.drozdgid.ru) — отдельное приложение. Панель отдаёт ей заявки, статусы и оплаты по токену, чтобы считать брони по каждой рекламе.

## Что умеет

- **Новая заявка.** Телефон, имя, «Как узнали» (группа → канал), слова клиента, дата праздника (точная или текстом «7 или 8.11»), куда писать, комментарий. Телефон любой записи (`+7 (985) 280-10-92`, `8985…`, `+ 7985…`) приводится к одному виду. Сразу видно, был ли уже этот клиент и кому уйдёт заявка.
- **Распределение.**
  1. Повторный клиент (тот же телефон за последние 30 дней) уходит своему прежнему менеджеру, если тот работает.
  2. Иначе заявку получает менеджер смены. Смена на день D — это сутки с 22:00 дня D-1 до 21:59 дня D: заявка в 21:59 уходит сегодняшнему менеджеру, с 22:00 — менеджеру следующего дня. Если на смене двое, её получает тот, у кого за эти сутки меньше заявок.
  3. Если на эти сутки никто не поставлен, заявка уходит менеджеру ближайшей смены с пометкой «поздняя».
  4. Администратор может выбрать менеджера вручную.
- **Таблица менеджера.** Тот же вид, что в «Бронях»: день → № → колонки. Ячейки правятся прямо в таблице: статусы, пакеты, источник и связь выбираются из списка. Карточка заявки (клик по №) хранит все поля, бронь (дата, время, комната, шоу, предоплата) и историю изменений.
- **Следующий контакт.** Дата и время, быстрые кнопки «+2 часа», «Завтра 10:00», «+3 дня».
- **Подсветка** (сверху вниз по важности), над таблицей счётчики-фильтры:

  | Цвет | Когда |
  | --- | --- |
  | красный «Просрочено» | время контакта прошло, а заявку после этого не меняли |
  | синий «Новая» | никто не нажал «Взял» и не поставил статус; через 15 минут ярче |
  | оранжевый «Сегодня» | контакт назначен на сегодня |
  | жёлтый «Нет следующего шага» | открытый статус (думает, обсуждаем, не дозвонились…), а контакт не назначен |
  | фиолетовый «Праздник скоро» | бронь оплачена, до праздника 3 дня или меньше |
  | зелёный «Нужен отзыв» | праздник прошёл, отзыва нет |
  | бледная строка | отказ, далеко, нецелевой, просто покататься, другое |

- **Уведомления в браузере** со звуком: новая заявка и «пора связаться». Работают, пока вкладка панели открыта; кнопка 🔔 включает разрешение. Telegram добавим, когда на сервере заработает прокси.
- **Расписание.** Календарь на месяц, смена = менеджер на весь день, без часов. Выбираете менеджера и натыкиваете дни: нажатие ставит или снимает, можно провести по дням, нажать на день недели (все понедельники месяца) или «Весь месяц». Есть копирование недели.
- **Менеджеры.** Логины, роли (владелец, администратор, банкетный менеджер), отключение уволенных. Менеджер видит только свои заявки, администратор и владелец видят все.
- **Источники.** Список «Как узнали» собран по чату Битрикс24, добавлены Instagram, 2ГИС и реклама на Ozon; каналы можно добавлять и скрывать. Новые каналы списка дописываются в работающую базу при запуске. Заявка с сайта с `utm_source=instagram`, `2gis` или `ozon` сразу получает нужный канал.
- **Сводка.** Заявки, брони, конверсия, отказы, предоплаты по менеджерам и источникам, причины отказов.

## Приём заявок с сайтов

`POST https://zayavki.drozdgid.ru/api/intake?token=<ZAYAVKI_INTAKE_TOKEN>&site=<метка сайта>`

- **Тильда** (оба сайта): «Настройки сайта → Формы → Webhook», адрес выше с `site=tilda-landing` или `site=tilda-site`. Поля `Name`, `Phone`, `utm_*` Тильда передаёт сама. Тестовый запрос Тильды (`test=test`) панель принимает без создания заявки.
- **Самописный сайт**: тот же адрес, JSON или форма с полями `phone`, `name`, `comment`, `utm_source`…`utm_term`, метка `site=site`.

Заявка с `utm_source=yandex` получает источник «Яндекс Директ», остальные с сайта — «Сайт».

## Выгрузка для консоли

`GET /api/export/leads?updated_since=2026-11-01T00:00` с заголовком `X-Export-Token: <ZAYAVKI_EXPORT_TOKEN>`: заявки, изменённые после даты, с UTM, статусом, пакетом, датой брони и предоплатой. Вместо `updated_since` можно передать `created_from` и `created_to` (даты): так забирает заявки консоль.

Тег «Как узнали» отдаётся полями `source_group` и `source_name`. По нему консоль считает заявки и брони по источникам («Яндекс Директ — 56 заявок / 12 броней»), когда у заявки нет UTM-метки и звонка через колтрекинг. В консоли это карточка «Панель заявок» во вкладке «Подключения»: адрес панели и `ZAYAVKI_EXPORT_TOKEN`.

## Запуск локально

```bash
pip install -r requirements-dev.txt
python -m pytest -q
ZAYAVKI_DATABASE_URL=sqlite:///./demo.db python tools/demo_seed.py   # примеры, вход owner / demo123
ZAYAVKI_DATABASE_URL=sqlite:///./demo.db python -m app serve --port 8100
```

## Выкатка на сервер (рядом с консолью)

1. DNS: A-запись `zayavki.drozdgid.ru` → IP сервера (тот же, что у `pult.drozdgid.ru`).
2. Скопировать папку `zayavki` в `/opt/zayavki`, создать `.env` по `.env.example` (секреты сгенерировать на сервере: `openssl rand -hex 32`).
3. `cd /opt/zayavki && docker compose up -d --build`. Приложение слушает только `127.0.0.1:8100`.
4. Первый вход: `docker compose exec zayavki-app python -m app create-user --login andrey --name "Андрей" --role owner` (пароль спросит).
5. HTTPS даёт системный Caddy (тот же, что у консоли). Сделать копию `cp /etc/caddy/Caddyfile /etc/caddy/Caddyfile.bak-$(date +%F)`, дописать в конец блок:

   ```
   zayavki.drozdgid.ru {
   	reverse_proxy 127.0.0.1:8100
   }
   ```

   затем `caddy validate --config /etc/caddy/Caddyfile && systemctl reload caddy`.
6. Проверить `https://zayavki.drozdgid.ru/healthz`.

В Google-таблицу «Брони» панель ничего не пишет.
